# Как выложить сайт в интернет (публикация)

Этот пакет уже готов к публикации: без админки, с превью для соцсетей,
страницами контактов и оферты, картой сайта и офлайн-режимом (PWA).

> **Важно.** Товары и цены теперь лежат в `content/products.json` — их правит
> владелец магазина через редактор Pages CMS, без кода. Порядок настройки
> редактора — в файле **`README-TOVARY.md`**. Если планируете менять
> цены сами, публикуйте сайт по варианту Б (через GitHub) — тогда правки будут
> попадать на сайт автоматически.

## Что внутри

```
index.html          витрина
contacts.html       контакты
offer.html          публичная оферта
privacy.html        политика конфиденциальности
404.html            страница «не найдено»
robots.txt          инструкции для поисковиков
sitemap.xml         карта сайта
sw.js               офлайн-кеш (service worker)
styles.css, app.js, catalog.js
content/            товары (products.json) и название магазина (site.json)  ← правится в редакторе
.pages.yml          настройка редактора Pages CMS
assets/             обложки, шрифты, иконки, og-cover.png, manifest
README-TOVARY.md   как менять товары и цены самому
```

## Вариант А. Быстро, без редактора (5 минут, но правки только через меня)

Подходит, если менять товары пока не собираетесь. Каждый раз, когда понадобится
правка, вы присылаете её мне и заново перетаскиваете папку на Netlify.

1. Откройте **app.netlify.com/drop** и войдите (Google, GitHub или e-mail).
2. Распакуйте этот архив в папку на компьютере.
3. Перетащите **папку** (не архив) в окно браузера — начнётся загрузка.
4. Через ~20 секунд появится адрес вида `random-name-123.netlify.app`.
   Site configuration → *Change site name* → введите `alex1ua` → адрес станет
   `alex1ua.netlify.app`. **Имя должно быть именно `alex1ua`** — документы и
   превью настроены на этот адрес. Если имя занято, Netlify предложит другое:
   возьмите любое и напишите мне — поменяю адрес в 3 файлах.
5. Откройте адрес на телефоне. iPhone: «Поделиться → На экран «Домой».
   Android: меню → «Установить приложение». Появится иконка, сайт откроется
   на весь экран и будет работать офлайн.

Обновление сайта: снова перетащите папку на тот же сайт (Deploys → Drag and drop).

## Вариант Б. Рекомендуется: GitHub + Netlify + редактор (30 минут один раз)

Сайт хранится в GitHub, Netlify публикует его автоматически после каждой правки,
а товары вы меняете через визуальный редактор Pages CMS с телефона или ПК.

Полная пошаговая инструкция — в файле **`README-TOVARY.md`**. Кратко:

1. github.com → новый репозиторий `alex-ua-shop` (Public) → *Add file → Upload files* →
   перетащить **содержимое** этой папки → *Commit changes*.
2. app.netlify.com → *Add new site → Import an existing project → GitHub* → выбрать
   репозиторий → Build command пустой, Publish directory `.` → *Deploy*.
   Затем *Change site name* → `alex1ua`.
3. app.pagescms.org → *Sign in with GitHub* → дать доступ к репозиторию → менять товары.

## Альтернативы

- **Cloudflare Pages**: dash.cloudflare.com → Workers & Pages → Create → Pages →
  Upload assets → загрузить архив.
- **GitHub Pages**: создать репозиторий → загрузить файлы → Settings → Pages →
  Branch: main. Адрес: `логин.github.io/репозиторий`.

## Свой домен (по желанию, для доверия)

1. Купите домен на imena.ua или ukraine.com.ua (~300–500 ₴/год).
2. Netlify: Domain management → *Add a domain you already own* → введите домен.
3. У регистратора пропишите DNS-записи, которые покажет Netlify (A/CNAME).
4. HTTPS-сертификат выдастся автоматически (Let's Encrypt).

## После публикации

- **Поисковики**: Google Search Console → добавить сайт → отправить `sitemap.xml`.
- **Аналитика**: Plausible (простая, без cookie-баннера) или Google Analytics 4 —
  добавьте скрипт в `index.html` перед `</head>`.
- **Реклама**: для Instagram/TikTok понадобится Meta Pixel — скажите, добавлю.
- **Проверка**: откройте сайт на телефоне, нажмите 2–3 кнопки «Купить» — должна
  открываться оплата BlackSea.

## Как обновлять товары

- **С редактором (Pages CMS):** раздел «Товары» → правка → *Save* → через ~30 секунд
  сайт обновлён. Подробно — `README-TOVARY.md`.
- **Файлом:** `content/products.json` — массив товаров; `content/site.json` — название,
  подпись, курс, ссылка на магазин. Их можно править и вручную на GitHub.
- **Через меня:** присылаете правки в чат, я пересобираю архив.
- `catalog.js` — встроенный запасной каталог: показывается, если `content/*.json`
  недоступны (например, страница открыта как локальный файл). Его можно не трогать.
- Новый товар на BlackSea: создать → скопировать `…/l/КОД` и
  `…/checkout?product=КОД&quantity=1` → заполнить в редакторе.

## Ограничения

- Оплата, чеки и выдача файлов — на BlackSea. Сайт только показывает товары.
- Отдельной админки-страницы в пакете нет: товары правит Pages CMS (внешний редактор),
  поэтому посетители не видят никаких кнопок редактирования.
