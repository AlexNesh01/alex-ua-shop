# Как менять товары и цены (редактор Pages CMS)

После этой настройки вы сможете добавлять товары, удалять их, менять цены и название магазина **с телефона или компьютера, без кода** — и сайт будет обновляться сам за ~30 секунд.

Как это устроено: товары лежат в файле `content/products.json`, название и курс — в `content/site.json`. Редактор (Pages CMS) показывает эти файлы как обычную форму с полями и кнопками «Добавить товар» / «Удалить». Сохранение = коммит в GitHub = автоматическая пересборка сайта на Netlify. Вам не нужно ничего писать в коде.

Настройка делается **один раз**, ~30 минут. Дальше — только правки.

---

## Часть 1. GitHub — там будут храниться файлы сайта

1. Откройте **github.com** → *Sign up* (можно через тот же Gmail: `alex10111888@gmail.com`). Подтвердите почту.
2. Нажмите **+** справа сверху → *New repository*.
3. Repository name: `alex-ua-shop`. Видимость: **Public** (сайт всё равно публичный, так проще). Нажмите *Create repository*.
4. На странице пустого репозитория: **Add file → Upload files**.
5. Распакуйте архив `alex-ua-publish.zip` в папку на компьютере. Откройте эту папку, выделите **всё содержимое** (Ctrl+A) и перетащите в окно браузера.
   ⚠️ Важно: тащить надо **содержимое папки**, а не саму папку — `index.html` должен оказаться в корне репозитория. Файл `.pages.yml` начинается с точки и на Windows может быть невидим — он должен быть загружен, иначе редактор не заработает.
6. Внизу нажмите **Commit changes**.

Проверка: в репозитории видно `index.html`, `app.js`, `catalog.js`, `styles.css`, папки `assets`, `content` и файл `.pages.yml`.

---

## Часть 2. Netlify — чтобы сайт открывался по ссылке

1. Откройте **app.netlify.com** → войдите (проще «Log in with GitHub»).
2. *Add new site* → **Import an existing project** → *Deploy with GitHub* → разрешите доступ → выберите репозиторий `alex-ua-shop`.
3. Настройки сборки:
   - Build command: **оставьте пустым**
   - Publish directory: **`.`** (одна точка — значит «всё из корня»)
4. *Deploy site*. Через минуту появится адрес вида `random-name-123.netlify.app`.
5. *Site configuration → Change site name* → введите `alex1ua` → адрес станет **`https://alex1ua.netlify.app`**.

С этого момента любой коммит в GitHub автоматически обновляет сайт.

## Часть 3. Pages CMS — сам редактор

1. Откройте **app.pagescms.org** → *Sign in with GitHub*.
2. Разрешите установку GitHub App для своего аккаунта и дайте доступ к репозиторию `alex-ua-shop`.
3. В списке выберите репозиторий. Появится меню слева:
   - **Товары** — список товаров
   - **Магазин (название, курс)** — название, подпись, курс гривны, ссылка на BlackSea
4. Откройте «Товары» — увидите 9 карточек. Внутри каждой: название, цена, валюта, категория, описание, картинка, ссылки и т. д.

Сохраните ссылку `app.pagescms.org` на экран «Домой» — это и есть ваша админка.

## Часть 4. Как менять товары (каждый день)

### Поменять цену
Товары → нужный товар → поле **Цена** (только число, например `6.5` или `250`) → **Валюта** (USD или UAH) → *Save*.
Через ~30 секунд на сайте новая цена. Вторая валюта считается сама по курсу из раздела «Магазин».

### Добавить товар
⚠️ Сначала заведите товар **на BlackSea** — там проходят оплата и выдача файлов. Скопируйте оттуда две ссылки: страницу товара и кнопку «Купить».

Товары → **Add item** (внизу списка) → заполните:
| Поле | Что писать |
|---|---|
| Название товара | «Планер 2027» |
| Цена | только число: `6.5` |
| Валюта | USD или UAH |
| Код товара | латиницей без пробелов: `planer-2027` (уникальный) |
| Категория | из списка: Книги / Приложения / Планеры / Шаблоны |
| Картинка | *Upload* — загрузите фото товара (лучше вертикальное, 800×1000) |
| Короткая подпись | одна строка под названием |
| Описание | текст для окна товара |
| Ссылка на страницу в BlackSea | `https://844129289197.blacksea.in.ua/l/<код>` |
| Ссылка «Купить» | `https://844129289197.blacksea.in.ua/checkout?product=<код>&quantity=1` |
| Цена текстом | только если цена не число (например `$0+`); иначе оставьте пусто |
| Плашка / Цвет плашки | `ХИТ ПРОДАЖ` + цвет `new` (зелёный) или `sale` (розовый) |
| Порядок | число побольше = карточка левее |

→ *Save*.

### Удалить товар
Товары → откройте товар → **Delete** (внизу или в меню справа) → подтвердите → *Save*.

### Скрыть товар, не удаляя
Поставьте цену `0` и в «Цена текстом» напишите `Скоро` — карточка останется, но не будет выглядеть как продающаяся.

### Поменять название магазина или курс
Раздел «Магазин (название, курс)» → правьте → *Save*. Название стоит в шапке сайта, курс влияет на пересчёт «≈ … ₴».

## Часть 5. Если что-то пошло не так

- **Сайт не обновился** — подождите минуту и обновите страницу с зажатым Shift. Проверьте на netlify.com → *Deploys*: последний деплой должен быть «Published».
- **Товар пропал с сайта** — скорее всего не заполнено «Название» или «Код товара». Откройте товар и проверьте.
- **Ошибка на странице** — почти всегда кривая ссылка. Ссылки должны начинаться с `https://`.
- **Хочу вернуть как было** — github.com → ваш репозиторий → вкладка *Commits* → у каждого изменения есть кнопка отката (Revert). Или напишите мне — откачу.
- **Редактор не видит репозиторий** — в настройках GitHub App (github.com/settings/installations) дайте доступ к `alex-ua-shop`.

---

## Чего нельзя делать

- Не удаляйте файлы `index.html`, `app.js`, `catalog.js`, `styles.css`, `.pages.yml`.
- Не переименовывайте папки `content` и `assets`.
- Не вписывайте в цену значки валюты и текст — только число. Значок сайт поставит сам.
- Не добавляйте товар только на сайт, минуя BlackSea: кнопка «Купить» приведёт в пустоту.

---

## Если правки нужны срочно, а редактор под рукой неудобен

Пришлите изменения в чат — «добавь товар … за …» или «поставь цену …» — я пересоберу файлы, а вы просто загрузите обновлённый `content/products.json` через GitHub (Add file → Upload files).
